# Language and JSON conventions (DomainInfo 6.0)

English is the source language of the whole repository: code, comments, docstrings, CLI help,
terminal UI, reports, tests, docs and commit messages.

## Translations

- Wrap every user-facing string (CLI messages, menu, terminal summaries, report text, finding titles,
  fixes, notes) in `tr()` from `i18n.py`. Use named placeholders: `tr("Open ports: {ports}", ports=...)`.
  Never build a translatable sentence by concatenating fragments.
- Spanish lives in catalog modules `i18n_es_<part>.py` with `STRINGS = {"English": "Español"}`.
  Parts: `ui` (domaininfo.py, terminal_ui.py, render.py, completions.py), `cli` (6.0 CLI/menu wiring), `modules` (all audit modules,
  score, infra, safety, evidence, webapp, tools), `phase2`, `phase3`, `phase4`.
- Placeholders must be identical in both languages (`tests/test_i18n.py` checks it).
- Language selection: `--lang en|es`, else `DOMAININFO_LANG`, else English.
- Free text stored in JSON (finding titles, fixes, notes) is written in the active language.
  **Enumerated values in JSON are always English** (table below), whatever the language.

## JSON enumerations (6.0)

| Field | 5.x / Phase-1 value → 6.0 value |
|---|---|
| severity (`score.findings[].severity`, findings) | `alta`→`high`, `media`→`medium`, `baja`→`low`, `info`→`info` |
| status (findings) | `confirmado`→`confirmed`, `probable`→`likely`, `informativo`→`informational`, `pendiente`→`pending`, `no_aplicable`→`not_applicable`, `no_evaluado`→`not_evaluated`, `error`→`error` |
| confidence | `alta`/`media`/`baja`→`high`/`medium`/`low` |
| check `state` | `ok`, `hallazgo`→`finding`, `no_aplicable`→`not_applicable`, `no_evaluado`→`not_evaluated`, `error` |
| check `evidence` | `directa`→`direct`, `heuristica`→`heuristic` |
| CSRF `state` | `token_visible`, `token_en_meta`→`token_in_meta`, `proteccion_alternativa`→`alternative_protection`, `desconocido`→`unknown`, `no_aplicable`→`not_applicable` |
| webapp finding `category` | `transporte`→`transport`, `redirecciones`→`redirects`, `hsts`, `csp`, `clickjacking`, `cabeceras`→`headers`, `cookies`, `formularios`→`forms`, `csrf`, `cors`, `errores`→`errors`, `exposicion`→`exposure` |
| webapp check `id` | `https`, `redirecciones`→`redirects`, `hsts`, `csp`, `clickjacking`, `nosniff`, `referrer`, `permissions`, `cookies`, `formularios`→`forms`, `csrf`, `cors`, `errores`→`errors`, `exposicion`→`exposure`, `raiz`→`root` |
| legacy score `area` | `Web`, `TLS`, `Correo`→`Mail`, `DNS`, `Puertos`→`Ports`, `Subdominios`→`Subdomains`, `Registro`→`Registration`, `Marca`→`Brand`, `Web app` |
| subdomain takeover `risk` | `alto`→`high`, `revisar`→`review` |
| lookalike `kind` | `omisión`→`omission`, `repetición`→`repetition`, `transposición`→`transposition`, `sustitución`→`replacement`, `homoglifo`→`homoglyph`, `guion`→`hyphenation`, `otro dominio superior`→`other TLD` (and any other kind: English snake/space words) |

Module `status` values (`ok`, `error`, `skipped`), mode and module names and every JSON **key** are unchanged.
